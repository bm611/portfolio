# Design Preferences

- Prefers a tech-focused logo (e.g., a terminal icon) over organic/leaf motifs. Asked for this change three times. Confidence: 0.95
- Prefers an earthy, nature-inspired palette: Forest Green `#2D4F1E`, Warm Beige `#F5E6CC`, Terracotta `#E27D60`, Slate Grey `#4A4A4A`. Confidence: 0.9
- Prefers card-based layouts with a lot of motion and micro-animations (staggered reveals, hover lift/tilt, glow, press-scale on tap) — high polish, not noisy. Confidence: 0.9
- Prefers a single cohesive theme over theme toggling (removed dark/light switch logic). Confidence: 0.8
- Cares strongly about mobile responsiveness: compact layouts at small widths (e.g., 2x2 grids), no horizontal overflow, no awkward gaps from chips/wrapping. Confidence: 0.9
- Prefers simple, flat card structure — one box with icon + text inside — over nested outer/inner boxes. Confidence: 0.85
- Prefers visually cohesive imagery; removes thumbnails/assets when colors, resolutions, or crops look inconsistent. Confidence: 0.8
- Prefers removing components that add clutter (e.g., an "active protocols" widget) and fixing the surrounding layout rather than keeping them. Confidence: 0.75
- Respects `prefers-reduced-motion`: keeps looping/ambient animation disabled and interaction usable for reduced-motion users. Confidence: 0.8
- Prefers a GitHub link in the navbar over a generic CTA button like "Start a Project". Confidence: 0.8
